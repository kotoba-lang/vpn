## 記載事項

### 1. 電気通信役務の種類

```
インターネット接続役務

（具体的内容）
WireGuardプロトコルを使用した仮想プライベートネットワーク（VPN）接続
サービス。利用者の通信をクラウドサーバー上のVPNサーバーを経由して
インターネットに接続し、通信の秘匿性を提供する。
サービス名称: vpn.etzhayyim.com
```

### 2. 業務区域

```
全国
```

### 3. 主たる事務所の所在地

```
東京都千代田区丸の内一丁目9番2号

（本店所在地と同じ）
```

### 4. 電気通信設備の概要

```
■ 設備の種別
  他社電気通信事業者（Vultr, Inc.）が管理・運営するクラウドサーバーを
  借用して利用するもの。自己の電気通信回線設備（固定回線・無線局）は
  設置しない。

■ 設備構成
  ・VPNサーバー: Vultr, Inc. 提供のクラウドサーバー（米国カリフォルニア州
    サンノゼ所在データセンター）上に構築
  ・使用プロトコル: WireGuard（RFC/IETF 準拠 VPN プロトコル）
  ・接続方式: UDP/51820 ポートによるピアツーピア型暗号化通信
  ・収容能力: 当初 1 サーバー、利用者数に応じ増設予定
  ・DNS リゾルバ: 同サーバー上の Unbound（プライベート DNS）

■ セキュリティ
  ・通信の暗号化: ChaCha20-Poly1305（WireGuard 標準）
  ・鍵管理: 利用者が端末上で生成した公開鍵のみを届出者が管理。
    秘密鍵は利用者端末外に持ち出さない。
  ・通信履歴: 接続元 IP アドレス・接続先 IP アドレス・通信内容を
    記録しない（プライバシーポリシーに明記）
```

## ⚠️ 提出前確認事項（CRITICAL）

### 1. 定款の事業目的 — 最重要

```
現状: GJ-CA-2026-001 (定款変更案 "single-family-private-office" 化)
      corporate_action_status = "draft" (未登記)

問題: 変更案の定款目的（資産管理・有価証券等）に「電気通信事業」が
      含まれていない。

選択肢:
  A. 定款変更前に届出 (現行定款が電気通信事業を包含しているか確認)
  B. 定款変更案に「電気通信事業」を追加してから登記 → 届出
  C. 別法人 (VPN 事業専用) で届出 → 推奨しない (コスト増)

→ 弁護士に「現行定款の事業目的が VPN 事業を包含するか」を確認すること
```

### 2. 役員の欠格事由確認

```
電気通信事業法第9条（準用）の欠格事由に代表者が該当しないこと:
  ✅ 破産者でないこと
  ✅ 電気通信事業法違反で罰金刑以上の執行後 2 年未満でないこと
  ✅ 成年被後見人・被保佐人でないこと
→ 河崎純真 氏: 特段問題なしと推定
```

### 3. no-logs ポリシーの利用規約・プライバシーポリシーへの記載

```
届出時に必須ではないが、事業開始前に整備が必要:
  ✅ プライバシーポリシー (通信履歴を記録しない旨)
  ✅ 利用規約 (免責事項・禁止行為・法執行機関への対応方針)
  ✅ 特定商取引法に基づく表示 (サービス名称・提供者・料金)
```

### 4. 刑事訴訟法197条2項への対応方針

```
捜査機関から「通信履歴保存要請」を受けた場合の対応を社内規程化すること:
  - 要請受領後 90 日間の保存義務が発生
  - 要請以前のログ不保存は合法
  → 「要請受領時プロトコル」を _working/vpn/law-enforcement-protocol.md に作成
```
