> 作成日: 2026-05-25  
> 承認者: 河崎純真（代表取締役）

## 基本方針

vpn.etzhayyim.com は**通信履歴を記録しない（no-logs）**ポリシーを採用する。

これは電気通信事業法第4条（通信の秘密の保護）に基づく利用者プライバシー保護の実践であり、
現行法上合法である（事前保存義務規定なし）。

---

## 捜査機関から要請を受けた場合の対応手順

### ステップ 1: 要請の受領・記録

```
□ 要請書類（令状・嘱託書・197条2項要請書等）の正本を受領
□ 受領日時・担当者名・要請機関名を記録
□ 代表者（河崎純真）に即時報告
□ 弁護士に連絡
```

### ステップ 2: 要請内容の確認

```
□ 令状の場合: 対象者 DID / 対象期間 / 発付裁判所 を確認
□ 197条2項要請の場合: 90日以内の保存義務が発生することを確認
□ 任意提出要請の場合: 弁護士判断を仰ぐ（強制力なし）
```

### ステップ 3: 保有情報の確認

```
no-logs ポリシーにより、以下の情報は保有していない（提供不可）:
  ⛔ 接続元 IP アドレス（クライアントの実 IP）
  ⛔ 接続先 IP アドレス・ドメイン（訪問先）
  ⛔ 接続タイムスタンプ（connect / disconnect）
  ⛔ 通信内容（WireGuard 暗号化 + no-log）
  ⛔ DNS クエリ履歴

保有している情報（提供可能）:
  ✅ アカウント存在確認（DID の存在 yes/no）
  ✅ 登録デバイス数・デバイス名（ラベルのみ）
  ✅ 課金情報（プラン・Stripe 顧客 ID）
  ✅ アカウント作成日時
```

### ステップ 4: 回答・対応

```
□ 弁護士立会いのもとで回答書を作成
□ 保有情報のみを書面で提供（保有しない情報は「記録なし」と明記）
□ 197条2項要請の場合: 要請受領日から 90 日間、以後の接続情報を保存開始
  （ただし要請以前のログは存在しないため提供不可）
□ 対応記録を社内保管（5年）
```

## 保存要請後の対応（刑事訴訟法197条2項）

要請受領後のみ、以下を限定的に記録する:

```python
# 要請受領後に限り収集する情報（要請終了または90日後に削除）
{
    "request_id": "<内部管理番号>",
    "target_did": "<対象 DID>",
    "request_received_at": "<受領日時>",
    "expires_at": "<受領日 + 90日>",
    # 以下は要請期間中のみ収集
    "connected_at": "<接続日時>",   # 通常は記録しないが要請中は記録
    "device_id": "<デバイス ID>"
    # 接続先 IP・DNS クエリは引き続き記録しない
}
```

**要請終了または90日経過後は即時削除する。**
